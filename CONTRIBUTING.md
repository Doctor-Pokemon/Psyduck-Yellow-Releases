# Reporting bugs and helping out

Thank you for testing **Pokémon Psyduck Yellow**! It is an unofficial fan project in beta, so bug reports are the most useful thing you can send.

## Reporting a bug
Open an **Issue** and use the *Bug report* form. Please include:
- the **version** (for example BETA 0.1.6.9),
- whether you play on an **emulator** (which one and its version) or a **3DS**,
- **what happened and what you expected**, and the **steps** to make it happen again,
- **screenshots and/or a video capture** if you can,
- your **save file's SHA-256 hash**, if possible (see below). Do not post the save file itself.

Softlocks and anything that stops you from progressing are the highest priority; please say where in the game you were.

### Getting a save hash (optional)
- Windows (PowerShell): `Get-FileHash "path\to\your.sav" -Algorithm SHA256`
- Linux / macOS: `sha256sum your.sav`

## Please never post
- **ROM files, game files or save files** (ours, Nintendo's, or anyone's). Issues containing them will be removed.
- Links to places that host ROMs.

## Questions and ideas
Use **Discussions** for questions, feedback and suggestions. Keep Issues for bugs.
